# 衣搭库 App 技术方案文档

## 一、文档概述

### 1.1 文档目的
本文档详细描述「衣搭库App AI衣物识别+智能穿搭推荐」的技术实现方案，采用豆包AI开放接口作为核心AI能力，通过接口适配层实现统一封装，涵盖端侧预处理、接口集成、断点续传、推荐算法、数据存储、性能优化和维护机制等核心模块。

### 1.2 技术目标
- **AI识别准确率**：上衣/裤子/裙子/鞋子≥95%，配饰≥80%；颜色识别≥90%；用户修正率≤10%
- **上传体验**：支持断点续传，网络中断后恢复上传成功率≥99%，单张照片上传耗时≤3秒（4G网络）
- **推荐效果**：衣橱≥10件时生成3-5套符合场合/天气/用户偏好的穿搭，7天内不重复推荐；衣橱<10件时提供通用搭配模板
- **隐私合规**：用户照片仅本地/加密云端存储，不上传公共服务器，支持一键删除所有数据
- **性能约束**：低端安卓机（内存≤4G）上识别单张照片耗时≤5秒

### 1.3 技术栈
- **移动端**：iOS 13+（Swift/SwiftUI），Android 8.0+（Kotlin/Jetpack Compose）
- **AI服务**：豆包AI开放接口（衣物识别+穿搭推荐能力）
- **后端**：Go语言（Gin/Echo框架）
- **接口适配层**：Go语言实现，统一API封装、异常重试、数据加密、结果解析
- **数据库**：MySQL（本地/云端）、Redis（缓存）
- **存储**：七牛云OSS（文件存储）

### 2.2 端侧预处理

#### 2.2.1 图片压缩
**压缩策略**：
- 目标大小：单张照片≤2MB（保证识别质量）
- 压缩质量：JPEG质量80-85%
- 分辨率限制：最大边≤2048px（保持清晰度）

**内存优化**：
- **Android**：使用inBitmap复用Bitmap内存，减少内存分配和GC压力
- **iOS**：使用UIGraphicsImageRenderer替代UIGraphicsBeginImageContext，降低内存占用

**iOS实现**（使用UIGraphicsImageRenderer降低内存占用）：
```swift
class ImagePreprocessor {
    func compressImage(_ image: UIImage, maxSizeKB: Int = 2000) -> Data? {
        var compression: CGFloat = 0.85
        var imageData = image.jpegData(compressionQuality: compression)
        
        // 如果压缩后仍过大，降低分辨率
        if let data = imageData, data.count > maxSizeKB * 1024 {
            let maxDimension: CGFloat = 2048
            let scale = min(maxDimension / image.size.width, 
                           maxDimension / image.size.height)
            if scale < 1.0 {
                let newSize = CGSize(width: image.size.width * scale,
                                   height: image.size.height * scale)
                // 使用UIGraphicsImageRenderer降低内存占用
                let resizedImage = image.resizedWithRenderer(to: newSize)
                imageData = resizedImage?.jpegData(compressionQuality: 0.85)
            }
        }
        
        // 二次压缩（如果仍过大）
        while let data = imageData, data.count > maxSizeKB * 1024 && compression > 0.5 {
            compression -= 0.05
            imageData = image.jpegData(compressionQuality: compression)
        }
        
        return imageData
    }
}

extension UIImage {
    /// 使用UIGraphicsImageRenderer进行图片缩放，降低内存占用
    func resizedWithRenderer(to size: CGSize) -> UIImage? {
        let renderer = UIGraphicsImageRenderer(size: size)
        return renderer.image { _ in
            self.draw(in: CGRect(origin: .zero, size: size))
        }
    }
}
```

**Android实现**（使用inBitmap复用Bitmap内存）：
```kotlin
import android.graphics.*
import java.io.ByteArrayOutputStream

class ImagePreprocessor {
    // Bitmap复用池，用于内存复用
    private val bitmapReusePool = mutableListOf<Bitmap>()
    private val poolLock = Any()
    
    fun compressImage(bitmap: Bitmap, maxSizeKB: Int = 2000): ByteArray? {
        var quality = 85
        var outputStream = ByteArrayOutputStream()
        bitmap.compress(Bitmap.CompressFormat.JPEG, quality, outputStream)
        
        // 如果压缩后仍过大，降低分辨率
        if (outputStream.size() > maxSizeKB * 1024) {
            val maxDimension = 2048
            val scale = minOf(maxDimension.toFloat() / bitmap.width,
                             maxDimension.toFloat() / bitmap.height)
            if (scale < 1.0f) {
                val newWidth = (bitmap.width * scale).toInt()
                val newHeight = (bitmap.height * scale).toInt()
                // 使用inBitmap复用内存
                val (resizedBitmap, isReused) = createScaledBitmapWithReuse(
                    bitmap, newWidth, newHeight
                )
                outputStream.reset()
                resizedBitmap?.compress(Bitmap.CompressFormat.JPEG, quality, outputStream)
                // 使用完后，将Bitmap返回池中以便后续复用
                resizedBitmap?.let { 
                    if (isReused) {
                        // 从池中复用的，使用完后返回池中
                        returnBitmapToPool(it)
                    } else {
                        // 新创建的，也可以加入池中以便后续复用
                        returnBitmapToPool(it)
                    }
                }
            }
        }
        
        // 二次压缩
        while (outputStream.size() > maxSizeKB * 1024 && quality > 50) {
            outputStream.reset()
            quality -= 5
            bitmap.compress(Bitmap.CompressFormat.JPEG, quality, outputStream)
        }
        
        return outputStream.toByteArray()
    }
    
    /**
     * 使用inBitmap复用机制创建缩放后的Bitmap
     * @return Pair<Bitmap, Boolean> - Bitmap和是否从池中复用的标志
     */
    private fun createScaledBitmapWithReuse(
        source: Bitmap,
        width: Int,
        height: Int
    ): Pair<Bitmap?, Boolean> {
        // 尝试从复用池获取可复用的Bitmap
        val reusableBitmap = getReusableBitmap(width, height, source.config)
        
        if (reusableBitmap != null) {
            // 使用Canvas在复用的Bitmap上绘制缩放后的图片
            val canvas = Canvas(reusableBitmap)
            canvas.drawColor(Color.TRANSPARENT, PorterDuff.Mode.CLEAR) // 清空内容
            val paint = Paint(Paint.ANTI_ALIAS_FLAG or Paint.FILTER_BITMAP_FLAG)
            val srcRect = Rect(0, 0, source.width, source.height)
            val dstRect = Rect(0, 0, width, height)
            canvas.drawBitmap(source, srcRect, dstRect, paint)
            return Pair(reusableBitmap, true) // 从池中复用
        }
        
        // 如果没有可复用的Bitmap，创建新的
        val newBitmap = Bitmap.createScaledBitmap(source, width, height, true)
        return Pair(newBitmap, false) // 新创建的
    }
    
    /**
     * 从复用池中获取可复用的Bitmap
     */
    private fun getReusableBitmap(
        width: Int,
        height: Int,
        config: Bitmap.Config
    ): Bitmap? {
        synchronized(poolLock) {
            val iterator = bitmapReusePool.iterator()
            while (iterator.hasNext()) {
                val bitmap = iterator.next()
                // 检查Bitmap是否可复用（大小和配置匹配）
                if (bitmap.isMutable &&
                    bitmap.width >= width &&
                    bitmap.height >= height &&
                    bitmap.config == config) {
                    iterator.remove()
                    return bitmap
                }
            }
        }
        return null
    }
    
    /**
     * 将Bitmap返回到复用池
     */
    private fun returnBitmapToPool(bitmap: Bitmap) {
        synchronized(poolLock) {
            // 限制池大小，避免内存占用过大
            if (bitmapReusePool.size < 5 && bitmap.isMutable) {
                bitmapReusePool.add(bitmap)
            } else {
                bitmap.recycle()
            }
        }
    }
    
    /**
     * 计算采样率
     */
    private fun calculateInSampleSize(
        reqWidth: Int,
        reqHeight: Int,
        width: Int,
        height: Int
    ): Int {
        var inSampleSize = 1
        if (reqWidth > width || reqHeight > height) {
            val halfWidth = reqWidth / 2
            val halfHeight = reqHeight / 2
            while ((halfWidth / inSampleSize) >= width &&
                   (halfHeight / inSampleSize) >= height) {
                inSampleSize *= 2
            }
        }
        return inSampleSize
    }
    
    /**
     * 清理复用池
     */
    fun clearReusePool() {
        synchronized(poolLock) {
            bitmapReusePool.forEach { it.recycle() }
            bitmapReusePool.clear()
        }
    }
}
```

#### 2.4.2 异常重试机制
**重试策略**（Go语言实现）：
```go
func (a *DoubaoAIAdapter) callAPIWithRetry(ctx context.Context, endpoint string, data map[string]interface{}) (map[string]interface{}, error) {
    var lastErr error
    
    for attempt := 0; attempt < a.retryConfig.MaxRetries; attempt++ {
        response, err := a.callAPI(ctx, endpoint, data)
        if err == nil {
            code, _ := response["code"].(float64)
            if code == 0 {
                return response, nil
            }
            
            // 可重试的错误码
            if code == 429 || code == 500 || code == 502 || code == 503 {
                lastErr = fmt.Errorf("retryable error: %v", response["message"])
                if attempt < a.retryConfig.MaxRetries-1 {
                    waitTime := time.Duration(math.Pow(float64(a.retryConfig.BackoffFactor), float64(attempt))) * time.Second
                    time.Sleep(waitTime)
                    continue
                }
            } else {
                // 不可重试的错误
                return nil, fmt.Errorf("non-retryable error: %v", response["message"])
            }
        } else {
            // 网络错误，可重试
            lastErr = err
            if attempt < a.retryConfig.MaxRetries-1 {
                waitTime := time.Duration(math.Pow(float64(a.retryConfig.BackoffFactor), float64(attempt))) * time.Second
                time.Sleep(waitTime)
                continue
            }
        }
    }
    
    return nil, fmt.Errorf("API调用失败，已重试%d次: %v", a.retryConfig.MaxRetries, lastErr)
}

func (a *DoubaoAIAdapter) callAPI(ctx context.Context, endpoint string, data map[string]interface{}) (map[string]interface{}, error) {
    url := a.baseURL + endpoint
    
    jsonData, err := json.Marshal(data)
    if err != nil {
        return nil, err
    }
    
    req, err := http.NewRequestWithContext(ctx, "POST", url, bytes.NewBuffer(jsonData))
    if err != nil {
        return nil, err
    }
    
    // 设置请求头
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+a.apiKey)
    
    // 签名（如需要）
    signature := a.signRequest(data)
    req.Header.Set("X-Signature", signature)
    
    resp, err := a.httpClient.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    
    var result map[string]interface{}
    if err := json.NewDecoder(resp.Body).Decode(&result); err != nil {
        return nil, err
    }
    
    return result, nil
}
```

#### 2.4.3 数据加密
**加密方案**（Go语言实现）：
```go
import (
    "crypto/hmac"
    "crypto/sha256"
    "encoding/hex"
    "sort"
    "strings"
    "time"
)

func (a *DoubaoAIAdapter) signRequest(data map[string]interface{}) string {
    // 1. 排序参数
    keys := make([]string, 0, len(data))
    for k := range data {
        keys = append(keys, k)
    }
    sort.Strings(keys)
    
    // 2. 拼接参数字符串
    var params []string
    for _, k := range keys {
        v := data[k]
        params = append(params, fmt.Sprintf("%s=%v", k, v))
    }
    paramString := strings.Join(params, "&")
    
    // 3. 拼接签名字符串
    timestamp := time.Now().Unix()
    signString := fmt.Sprintf("%s%d%s", a.apiKey, timestamp, paramString)
    
    // 4. HMAC-SHA256签名
    h := hmac.New(sha256.New, []byte(a.apiSecret))
    h.Write([]byte(signString))
    signature := hex.EncodeToString(h.Sum(nil))
    
    return signature
}

func (a *DoubaoAIAdapter) encryptSensitiveData(data map[string]interface{}) map[string]interface{} {
    // 使用AES加密敏感数据
    encryptedData := make(map[string]interface{})
    sensitiveFields := []string{"user_id", "device_id"}
    
    for key, value := range data {
        if contains(sensitiveFields, key) {
            // 使用AES加密
            encrypted, err := aesEncrypt(fmt.Sprintf("%v", value), a.encryptionKey)
            if err == nil {
                encryptedData[key] = encrypted
            }
        } else {
            encryptedData[key] = value
        }
    }
    
    return encryptedData
}
```

```go
func (a *DoubaoAIAdapter) parseResponse(response map[string]interface{}) map[string]interface{} {
    code, _ := response["code"].(float64)
    if code != 0 {
        message, _ := response["message"].(string)
        return map[string]interface{}{
            "error": fmt.Sprintf("API返回错误: %s", message),
        }
    }
    
    data, ok := response["data"].(map[string]interface{})
    if !ok {
        return response
    }
    
    // 转换为内部统一格式
    if category, exists := data["category"]; exists {
        categoryMap := category.(map[string]interface{})
        colors := data["colors"].([]interface{})
        
        result := map[string]interface{}{
            "category": map[string]interface{}{
                "name":        categoryMap["name"],
                "confidence":  categoryMap["confidence"],
                "subcategory": categoryMap["subcategory"],
            },
            "styles": data["styles"],
            "season": data["season"],
        }
        
        // 转换颜色数组
        colorList := make([]map[string]interface{}, 0)
        for _, c := range colors {
            colorMap := c.(map[string]interface{})
            colorList = append(colorList, map[string]interface{}{
                "name":       colorMap["name"],
                "rgb":        colorMap["rgb"],
                "proportion": colorMap["proportion"],
            })
        }
        result["colors"] = colorList
        
        return result
    }
    
    if outfits, exists := data["outfits"]; exists {
        outfitList := outfits.([]interface{})
        result := make([]map[string]interface{}, 0)
        
        for _, o := range outfitList {
            outfitMap := o.(map[string]interface{})
            result = append(result, map[string]interface{}{
                "outfit_id":          outfitMap["outfit_id"],
                "item_ids":            outfitMap["items"],
                "score":               outfitMap["score"],
                "highlights":          outfitMap["highlights"],
                "suitable_occasions":  outfitMap["suitable_occasions"],
            })
        }
        
        return map[string]interface{}{
            "outfits": result,
        }
    }
    
    return data
}
```

```python
    def track_recognition_result(self, item_id: str, api_result: dict, user_correction: dict = None):
        """追踪识别结果和用户修正"""
        if user_correction:

    def calculate_accuracy(self, api_result: dict, user_correction: dict) -> float:
        """计算准确率"""
        correct = 0
        total = 0
        
        # 品类准确率
        if api_result['category']['name'] == user_correction['category']:
            correct += 1
        total += 1
        
        # 颜色准确率（允许部分匹配）
        api_colors = set([c['name'] for c in api_result['colors']])
        user_colors = set(user_correction['colors'])
        color_match = len(api_colors & user_colors) / max(len(api_colors), len(user_colors))
        correct += color_match
        total += 1
        
        return correct / total
```

#### 3.1.1 文件分块策略
**分块大小**：
- 默认：1MB/块
- 动态调整：根据网络状况（4G/5G/WiFi）调整块大小
- 最小块：256KB（避免过多请求）

**分块算法**：
```python
class ChunkUploader:
    def __init__(self, file_path, chunk_size=1024*1024):
        self.file_path = file_path
        self.chunk_size = chunk_size
        self.file_size = os.path.getsize(file_path)
        self.total_chunks = (self.file_size + chunk_size - 1) // chunk_size
        self.chunks = []
    
    def split_file(self):
        """将文件分割为多个块"""
        with open(self.file_path, 'rb') as f:
            for i in range(self.total_chunks):
                chunk_data = f.read(self.chunk_size)
                chunk_hash = hashlib.md5(chunk_data).hexdigest()
                self.chunks.append({
                    'index': i,
                    'data': chunk_data,
                    'hash': chunk_hash,
                    'size': len(chunk_data)
                })
        return self.chunks
```

```python
class UploadResumeManager:
    def __init__(self):
        self.network_monitor = NetworkMonitor()
        self.upload_queue = UploadQueue()
        self.network_monitor.on_network_available = self.resume_uploads
    
    def resume_uploads(self):
        """网络恢复后自动恢复上传"""
        pending_tasks = self.upload_queue.get_pending_tasks()
        for task in pending_tasks:
            self.resume_task(task.task_id)
    
    def resume_task(self, task_id):

        task = self.upload_queue.get_task(task_id)

        total_chunks = task.total_chunks
        
        # 从未上传的块开始继续上传
        for chunk_index in range(total_chunks):
            if chunk_index not in uploaded_chunks:
                self.upload_chunk(task_id, chunk_index)
```

```python
class UploadQueue:
    def get_next_task(self):

        tasks = self.db.query("""
            SELECT * FROM upload_tasks 
            WHERE status IN ('pending', 'failed')
            ORDER BY 
                CASE WHEN status = 'failed' THEN 1 ELSE 0 END,
```

#### 3.4.3 并发控制
**并发策略**：
- 同时最多3个上传任务并发
- 每个任务内部：串行上传块（避免网络拥塞）
- 批量上传：9张照片，每张独立任务，最多3个并发

**实现**：
```swift
class UploadManager {
    private let maxConcurrent = 3
    private var activeTasks: [String: UploadTask] = [:]
    private let queue = DispatchQueue(label: "UploadQueue", attributes: .concurrent)
    
    func addTask(_ task: UploadTask) {
        queue.async { [weak self] in
            self?.processQueue()
        }
    }
    
    private func processQueue() {
        while activeTasks.count < maxConcurrent {
            guard let nextTask = uploadQueue.getNextTask() else { break }
            startUpload(nextTask)
        }
    }
    
    private func startUpload(_ task: UploadTask) {
        activeTasks[task.id] = task
        // 开始上传...
        task.completion = { [weak self] in
            self?.activeTasks.removeValue(forKey: task.id)
            self?.processQueue()  // 继续处理队列
        }
    }
}
```

#### 3.4.4 失败重试机制
**重试策略**：
- 最多重试3次
- 指数退避：第1次重试等待1秒，第2次2秒，第3次4秒
- 超过3次：标记为失败，用户可手动重试

**实现**：
```python
class ChunkUploader:
    def upload_chunk_with_retry(self, task_id, chunk_index, max_retries=3):
        for attempt in range(max_retries):
            try:
                result = self.upload_chunk(task_id, chunk_index)
                if result['status'] == 'success':
                    return result
            except NetworkError as e:
                if attempt < max_retries - 1:
                    wait_time = 2 ** attempt  # 指数退避
                    time.sleep(wait_time)
                else:
                    self.mark_chunk_failed(task_id, chunk_index)
                    raise
```

3. **用户行为数据**（优化）：基于历史行为调整推荐权重

#### 4.1.2 推荐流程
```python
class OutfitRecommender:
    def __init__(self):
        self.doubao_adapter = DoubaoAIAdapter()
        self.rule_engine = RuleEngine()
        self.user_behavior_tracker = UserBehaviorTracker()
    
    def recommend(self, user_id, occasion, weather, user_preferences):
        # 1. 获取用户衣橱
        wardrobe = self.get_user_wardrobe(user_id)
        
        # 2. 判断用户状态（冷启动/标准）
        if len(wardrobe) < 10:
            return self.cold_start_recommend(occasion, weather, user_preferences)
        
        # 3. 调用豆包AI推荐接口
        doubao_results = self.doubao_adapter.recommend_outfit(
            wardrobe=wardrobe,
            occasion=occasion,
            weather=weather,
            preferences=user_preferences
        )
        
        # 4. 本地后处理
        # 4.1 规则引擎过滤（确保符合基本穿搭规则）
        filtered_outfits = self.rule_engine.filter(doubao_results['outfits'], occasion, weather)
        
        # 4.2 基于用户行为调整权重
        adjusted_outfits = self.adjust_by_user_behavior(user_id, filtered_outfits)
        
        # 4.3 去重和多样性保证
        final_outfits = self.deduplicate(adjusted_outfits, user_id)
        final_outfits = self.ensure_diversity(final_outfits)
        
        return final_outfits[:5]  # 返回Top 5
    
    def adjust_by_user_behavior(self, user_id, outfits):
        """基于用户行为调整推荐权重"""
        behavior_data = self.user_behavior_tracker.get_user_behavior(user_id)
        
        for outfit in outfits:
            # 如果用户之前收藏过类似搭配，提升权重
            if self.is_similar_to_favorites(outfit, behavior_data['favorites']):
                outfit['score'] *= 1.2
            
            # 如果用户之前不感兴趣，降低权重
            if self.is_similar_to_dislikes(outfit, behavior_data['dislikes']):
                outfit['score'] *= 0.8
        
        # 重新排序
        outfits.sort(key=lambda x: x['score'], reverse=True)
        return outfits
```

```python
class RuleEngine:
    def __init__(self):
        self.rules = self.load_rules()
    
    def score(self, candidates, occasion, weather, user_preferences):
        scores = {}
        for item in candidates:
            score = 0.0
            # 1. 场合适配规则
            score += self.match_occasion_rule(item, occasion) * 0.3
            # 2. 天气适配规则
            score += self.match_weather_rule(item, weather) * 0.2
            # 3. 用户偏好规则
            score += self.match_preference_rule(item, user_preferences) * 0.3
            # 4. 基础搭配规则（颜色、风格）
            score += self.match_basic_rules(item) * 0.2
            scores[item.id] = score
        return scores
    
    def match_occasion_rule(self, item, occasion):
        """场合适配规则"""
        rules = self.rules.filter(type='occasion', condition={'occasion': occasion})
        score = 0.0
        for rule in rules:
            if self.check_condition(item, rule.condition):
                score += rule.weight
        return min(score, 1.0)  # 归一化到[0,1]
```

```python
class CollaborativeFilter:
    def __init__(self):
        self.user_item_matrix = self.build_matrix()
    
    def score(self, user_id, candidates):
        """基于协同过滤评分"""
        # 1. 找到相似用户
        similar_users = self.find_similar_users(user_id, k=10)
        
        # 2. 计算候选物品的预测评分
        scores = {}
        for item in candidates:
            score = 0.0
            for similar_user, similarity in similar_users:
                if item.id in similar_user['favorite_items']:
                    score += similarity * 1.0  # 相似用户喜欢的物品
            scores[item.id] = score
        return scores
    
    def find_similar_users(self, user_id, k=10):
        """找到K个最相似用户"""
        user_vector = self.user_item_matrix[user_id]
        similarities = []
        for other_user_id, other_vector in self.user_item_matrix.items():
            if other_user_id != user_id:
                similarity = cosine_similarity(user_vector, other_vector)
                similarities.append((other_user_id, similarity))
        similarities.sort(key=lambda x: x[1], reverse=True)
        return similarities[:k]
```

### 4.6 去重与多样性保证

#### 4.6.1 去重机制
**7天内不重复推荐**：
```python
def deduplicate(outfits, user_id):
    """去除7天内已推荐过的搭配"""
    recent_outfits = get_recent_outfits(user_id, days=7)
    recent_item_ids = set()
    for outfit in recent_outfits:
        recent_item_ids.update(outfit['item_ids'])
    
    filtered_outfits = []
    for outfit in outfits:
        outfit_item_ids = set(item['id'] for item in outfit['items'])
        # 如果搭配中所有单品都在最近推荐过，则跳过
        if not outfit_item_ids.issubset(recent_item_ids):
            filtered_outfits.append(outfit)
    
    return filtered_outfits
```

#### 4.6.2 多样性保证
**多样性策略**：
1. **风格多样性**：确保3-5套推荐涵盖不同风格
2. **颜色多样性**：避免所有推荐都是同一色系
3. **品类多样性**：确保不同单品组合

**实现**：
```python
def ensure_diversity(outfits, max_outfits=5):
    """保证推荐方案的多样性"""
    selected = []
    used_styles = set()
    used_colors = set()
    
    for outfit in outfits:
        # 检查风格多样性
        outfit_styles = set(outfit['styles'])
        if outfit_styles.issubset(used_styles) and len(selected) > 0:
            continue  # 风格重复，跳过
        
        # 检查颜色多样性
        outfit_colors = set(outfit['main_colors'])
        if outfit_colors.issubset(used_colors) and len(selected) > 2:
            continue  # 颜色重复，跳过
        
        selected.append(outfit)
        used_styles.update(outfit_styles)
        used_colors.update(outfit_colors)
        
        if len(selected) >= max_outfits:
            break
    
    return selected
```

```go
type EncryptedStorage struct {

    aesKey   []byte

func (e *EncryptedStorage) UploadEncryptedImage(ctx context.Context, userID string, imageData []byte, itemID string) (string, error) {
    // 1. 加密图片数据
    encryptedData, err := e.encryptAES(imageData, e.getUserKey(userID))
    if err != nil {
        return "", err
    }
    
    // 2. 上传到七牛云OSS
    key := fmt.Sprintf("users/%s/items/%s/%d.enc", userID, itemID, time.Now().Unix())
    url, err := e.qiniuOSS.UploadFile(key, encryptedData)
    if err != nil {
        return "", err
    }
    
    return url, nil
}

func (e *EncryptedStorage) encryptAES(data []byte, key []byte) ([]byte, error) {
    block, err := aes.NewCipher(key)
    if err != nil {
        return nil, err
    }
    
    gcm, err := cipher.NewGCM(block)
    if err != nil {
        return nil, err
    }
    
    nonce := make([]byte, gcm.NonceSize())
    if _, err := io.ReadFull(rand.Reader, nonce); err != nil {
        return nil, err
    }
    
    ciphertext := gcm.Seal(nonce, nonce, data, nil)
    return ciphertext, nil
}
```

```python
def resolve_conflict(local_item, cloud_item):
    """解决编辑冲突"""
    # 1. 最后写入获胜（默认策略）
    if cloud_item['last_modified'] > local_item['last_modified']:
        return cloud_item
    
    # 2. 字段级合并（对于可合并字段）
    merged = {
        'item_id': local_item['item_id'],
        'category': local_item['category'],  # 以本地为准
        'tags': list(set(local_item['tags'] + cloud_item['tags'])),  # 合并标签
        'notes': local_item['notes'] if local_item['notes'] else cloud_item['notes'],
        'last_modified': max(local_item['last_modified'], cloud_item['last_modified'])
    }
    
    # 3. 关键字段冲突：提示用户选择
    if local_item['category'] != cloud_item['category']:
        # 触发用户选择界面
        return prompt_user_choice(local_item, cloud_item)
    
    return merged
```

```
    ↓（端侧预处理：图片压缩/匿名化/分块）
接口适配层（统一API封装/异常重试/数据加密）
    ↓（HTTPS加密传输）
豆包AI开放接口（衣物识别+穿搭推荐能力）
    ↓（返回结构化结果）
接口适配层（结果解析/格式转换/缓存）
    ↓
衣搭库App（结果展示/用户交互/本地存储）
```

### 8.2 关键技术选型总结

| 模块 | 技术选型 | 理由 |
|------|---------|------|
| **移动端** | iOS: Swift/SwiftUI<br>Android: Kotlin/Jetpack Compose | 原生性能，现代化UI框架 |
| **AI服务** | 豆包AI开放接口 | 无需自建模型，降低开发运维成本，准确率高 |
| **接口适配层** | Python/Node.js | 统一API封装，异常重试，数据加密，结果解析 |
| **后端框架** | Go语言（Gin/Echo） | 高性能，并发能力强，适合API服务 |
| **数据库** | MySQL | 成熟稳定的关系型数据库，支持JSON字段 |
| **缓存** | Redis | 高性能内存缓存，减少API调用 |
| **文件存储** | 七牛云OSS | 国内CDN加速，上传下载速度快 |
| **图片处理** | 端侧预处理 | 图片压缩、匿名化、分块处理 |
