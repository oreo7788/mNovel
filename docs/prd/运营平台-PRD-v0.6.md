# PRD: 支付运营平台（运营后台）v0.6

> **聚焦功能与展示数据，不约束 UI。**
> 相对 v0.5：**通道管理全量补全**（列表全列、编辑表单、开发配置、绑定、5 个行内设置弹窗、通道测试）；**商户补全**（调额弹窗、通道绑定、分组表单、更多操作弹窗）；代理详情、角色权限弹窗；**登录页更正**（无谷歌验证码字段、无忘记密码、无底部信息）。
> 仍缺：订单详情/补单/回调、有数据的提现审核弹窗、异常订单有数据与操作、数据统计有数据行/展开下拉（枚举与示例值）、利润公式。

## Overview

### Problem Statement

支付聚合运营需在统一后台完成商户/代理/通道/供应商配置、订单与异常处理、多主体提现审核、账务审计与日终对账，以及系统参数与权限管控。

### Solution Summary

建设 B 端运营平台，覆盖：

| 域 | 能力 |
|----|------|
| 准入 | 登录（图形码） |
| 总览 | 首页看板 + 顶栏提现待办/系统开关 + 商户/通道/代理速览 |
| 主体 | 商户、代理、通道、供应商、通道类型 |
| 交易 | 订单、异常订单 |
| 资金 | 商户/代理/通道提现；调额、结算、预付预警 |
| 统计 | 账户流水 + 多维日终报表 |
| 系统 | 参数、机器人、用户角色、日志 |

### Target Users

运营超管、运营专员、财务（提现审核暂定）；商户/代理为独立端（系统配置中有商户平台 URL）；角色类型含运营平台 / 商户系统 / 代理系统。

## Goals & Success Metrics

1. P0/P1 模块字段相对对标截图覆盖 ≥ 90%（已截模块目标）
2. 资金类操作（调额、结算、提现、改费率）可审计（操作日志）
3. 日终与账户流水可按主体导出对账；「今日」口径与日切一致
4. RBAC：角色可配置菜单/操作权限；系统角色受保护不可删；提现审核权限可分配

## 全局业务约定（v0.4 起，保留）

| 约定 | 定义 |
|------|------|
| 日切 | **每天 00:00，时区 UTC+8**；首页「今日/昨日」与日终统计按此切日 |
| 费率单位 | 界面小数 `0.003` = **3‰**；商户费率与通道费率**同一套**表示 |
| 总金额 | **收单金额**（含未支付等收单口径） |
| 成交额 | **已支付金额** |
| 系统开关关闭 | **拒收新单**（与系统配置「系统开启」一致） |
| 利润公式 | 商户费率 / 通道费率 / 代理费率如何拆利润、入账 — **未知，待研发确认** |
| 技术实现 | **不基于**本仓库现有 `web/`（Vue）；另起实现栈 |

## Scope

### In Scope（v0.6 可开发）

- v0.5 全部内容
- **通道管理全量**：列表全列、创建/编辑表单、开发配置、绑定、行内设置（通道费率/代理费率/轮询权重/提现服务费/信用额度）、通道测试

- 代理详情、角色权限分配弹窗（菜单/操作树）
- 登录页更正

### Out of Scope / 待补图（本版不锁细节）

- 首页右侧**监控区** — 产品确认**暂时不考虑**
- 订单详情、补单弹窗、回调结果界面
- 商户/代理/通道提现**有数据列表 + 审核弹窗**样例
- 异常订单有数据列表与操作后界面
- 数据统计**有数据行 / 展开「类型」「是否盈利」「来源」下拉**（解锁枚举与示例值）
- 代理是否与商户功能完全对称（白名单/分组/通道配置等）— **未确认**

### Non-Goals

- 不复刻 UI；不含商户端/代理端产品本身（仅运营侧配置其 URL）
- 不在本 PRD 固定前端框架选型（仅排除沿用本仓 `web/`）

### 3. 商户管理（v0.6 补全弹窗）

#### 3.1 列表

**筛选区**：商户号、商户名称、代理名称（下拉）、状态（下拉）、商户分组（下拉）。

**顶部批量操作**：+创建、导出、**一键全部启用**、一键修改费率、结算设置、一键结算、分组管理、批量删除。

**列**：#、商户号、商户名称、代理名称、提现手续费、预付款（可为负，红色）、余额（含「**调整**」=调额入口）、状态（「正常」）、创建时间、操作。

**操作列**：编辑、通道配置、通道绑定、**更多**。

**「更多」下拉（9 项）**：编辑、详情、查看商户密钥、重置登录密码、重置提现密码、重置收款密码、重置商户密钥、测试、删除。

#### 3.2 新建 / 编辑表单

**新建**（「创建商户信息」）：商户名称\*、提现手续费\*（默认 `0`）、代理名称（下拉）、商户分组（下拉）、登录IP白名单、提现接口IP白名单、群组ID\*（默认 `0`）、状态（开关，默认开）、登录账号\*。

**编辑**（「更新商户信息」）= 新建字段 + **编辑独有**：**群发时艾特账号**、**群发艾特开关**（默认开）。

> - 必填：商户名称、提现手续费、群组ID、登录账号。
> - IP 白名单为文本域，多个用「**|**」分隔。
> - 代理名称下拉值带编号前缀，如 `[A1774607455]振兴`。
> - 群发艾特 2 字段疑似与系统配置/机器人「群发商户艾特总开关」联动。

#### 3.3 通道配置（抽屉）

展示商户号/名称；列表：支付通道（勾选）、商户费率、返佣费率；通道行格式「[编码]名称」；「已选择 N 行」；确定/取消。

#### 3.4 通道绑定（抽屉，v0.6 新增）

展示已绑定通道列表：通道名称、通道费率、状态（启停）；支持绑定/解绑。

#### 3.5 一键修改费率（抽屉）

左侧目标商户批量勾选；右侧：通道类型\*、商户费率\*（小数，`0.003`=3‰）、操作类型\*（**全部商户 / 选择商户 / 商户分组**）、自助开通（**下拉 是/否**）、叠加代理费率（**下拉 是/否**）。

#### 3.6 商户分组管理（弹窗）

筛选：分组名称、状态；查询/刷新；+ 创建。列：#、分组名称、状态（「正常」绿标）、备注、创建时间、编辑/删除。

**新建/编辑表单（v0.6 新增）**：分组名称\*、状态（开关/正常）、备注。

#### 3.7 一键修改结算配置（抽屉）

是否自动结算（开关，默认关）、每天自动结算时间（如 `23:00:00`）、结算方式（**余额清零**=累计跑量 / **结算昨日**=仅昨日跑量）；三字段必填；左侧目标商户批量勾选。

#### 3.8 调额弹窗（v0.6 新增）

余额/预付款资金调整：调整类型（增加/减少）、金额、备注。属资金类操作，**需写入操作日志**。

#### 3.9 更多操作弹窗（v0.6 新增）

- **详情**：商户只读详情（商户号、名称、代理、分组、费率、余额、预付款、各白名单、群组ID、状态、创建/时间等全字段）。
- **查看商户密钥**：展示商户号、商户密钥（MD5）等接入凭证（敏感，需权限）。
- **编辑**：同 §3.2 编辑表单。
- **重置登录/提现/收款密码、重置商户密钥**：二次确认后执行，写入操作日志。
- **测试**：对该商户发起测试支付。

#### 3.10 仍待补图

更多菜单内各弹窗的精确校验提示与二次确认文案（沿用系统通用确认即可）。

### 5. 通道管理（v0.6 全量补全）

#### 5.1 列表（列与操作据 `通道管理-列表 1/2.png`）

**筛选**：通道编码、通道名称、通道类型、状态；查询、重置、+ 创建。

**列**（自左至右）：复选框、#、通道编码、通道名称、通道类型、状态、**成功率（昨日）**、**成功率（今日）**、**轮询权重**、余额（含**提现/调额**入口）、**信用额度**（含**设置**）、**提现服务费**、**通道费率（三档）**、金额区间/收款方式、**工作指标**、操作。

**操作列**：编辑、**开发配置**、**绑定**、复制、删除、**测试**；行内「设置」入口见 §5.5。

> 「工作指标」列含义待确认（Open Questions）。

#### 5.2 创建 / 编辑（`通道管理-编辑-清晰.png`）

字段分组：
- **基本信息**：通道编码、通道名称、通道类型、状态、轮询权重、信用额度、提现服务费
- **通道费率（三档）**：按金额区间分档设置费率（如 `0-1000 / 1000-5000 / 5000+` 各档费率，小数 ‰ 语义）
- **收款方式与规则**：收款方式（下拉）；金额规则为**区间**（如 `100-5000`）或**固定值**（如 `98|199|...`）
- **网关/回调**：回调地址、支付网关等
- **开发配置参数**：见 §5.3

#### 5.3 开发配置（`通道管理-开发配置.png`）

通道对接上游的接入参数：商户号/应用ID、密钥、公钥/私钥、回调地址、支付方式映射、签名方式等（受安全配置「开启通道开发配置」开关控制）。

#### 5.4 绑定（`通道管理-绑定.png`）

展示该通道的绑定关系（商户/代理/供应商）列表，支持绑定/解绑与启停。

#### 5.5 行内设置弹窗（5 个，v0.6 新增）

| 弹窗 | 设置内容 |
|------|---------|
| 通道费率设置 | 三档费率（按区间） |
| 代理费率设置 | 按代理设置代理费率 |
| 轮询权重设置 | 轮询权重 |
| 提现服务费设置 | 提现服务费 |
| 信用额度设置 | 信用额度（+ 开关） |

> 各弹窗均为资金/费率类操作，**需写入操作日志**。

#### 5.6 通道测试（`通道管理-通道测试.png`）

对该通道发起测试支付：金额、商户、收款方式等；返回测试结果（用于验证通道可用性）。对应商户「更多-测试」。

### 7. 供应商管理（v0.5 更正：无导出）

- **列**：#、编码（如 `G1782621882`）、名称、状态（开关）、信用额度（金额 + 开/关 + **设置**）、预付（金额 + **调额**）、应下发金额、实时预付余额（**可负，红色**）、今日成功金额、备注、创建时间、操作（编辑、删除、通道绑定）
- **合计行**：含信用额度、预付、应下发金额、实时预付余额、今日成功金额

#### 7.2 创建（「创建供应商」）

供应商名称\*、状态（默认开）、群组 id\*（默认 `0`）、备注（文本域）

#### 7.3 编辑（「更新供应商」）增量

供应商预付不足提醒金额（必填，`0`=不提醒）、预付不足提醒艾特账号（标签式多选，「请输入用户名按回车」）、是否艾特（开关，默认开）、结算方式、是否自动结算（开关，默认关）、每天自动结算时间（如 `23:50:59`）。

> ⚠️ **用词不一致**：编辑弹窗结算方式文案为「结算昨日(只结算**商户**昨日的跑量)」，批量结算设置用「**供应商**」。建议统一。

#### 7.4 通道绑定（抽屉）

顶部：供应商编码/名称；列：#、通道名称（如 `[968] wx`）、通道类型、操作（解绑 + 启停开关）。**无筛选/新增/分页**。

#### 7.5 结算设置 / 预付预警 / 一键结算 / 删除（同 v0.5）

- 结算设置（批量，「一键修改结算配置」）：是否自动结算、每日时间、结算方式（余额清零 / 结算昨日），均必填。
- 预付预警（批量，「一键修改预付预警金额」）：提醒金额（必填，默认 `0`）。
- 一键结算确认：「你确定执行[余额清零]操作吗?」
- 删除确认：「您确定删除选中的记录吗?」

## User Stories（摘要）

1. 作为超管，我关闭系统开关后，平台不再接收新支付单，以便紧急止损。
2. 作为运营，我在代理管理中创建代理并设置登录账号与提现服务费。
3. 作为运营，我在首页商户/通道/代理 Tab 快速查看主体状态与余额合计。
4. 作为财务，我审核提现时通过可不填备注、拒绝必须说明原因。
5. 作为运营，我按「全部商户 / 选择商户 / 商户分组」批量修改指定通道类型费率。
6. 作为运营，我按 UTC+8 自然日查看今日/昨日指标与日终报表并对账。
7. 作为运营，我在商户列表「更多」菜单一键重置各类密码或查看商户密钥。
8. 作为运营，我在通道管理配置三档费率、收款规则、开发配置，并对通道做行内费率/权重/信用额度调整与测试。

| 系统关闭后新单 | 拒收；在途单行为见 Open Questions |
| 日终/账户无数据 | 空态；导出策略产品二选一 |
| 改费率/调额且「通知到群」开 | 触发群通知（依赖机器人） |
| IP 白名单多值 | 用竖线「\|」分隔 |
| 资金类操作（调额/改费率/结算/提现） | 全部写入操作日志 |

## Technical Considerations

- **不复用**本仓库 `web/`（Vue）作为前端基线
- 结算任务：商户/供应商 Cron + 结算方式分支
- 账户流水成对记录新旧余额；日终按 UTC+8 日切聚合或可重算
- 配置项 KV + **区块级保存**；系统开关与配置「系统开启」同源
- 费率统一小数比例（‰ 语义）
- 机器人与群通知为外部 IM 集成
- 利润/入账公式未定，实现前需研发给出并回填
- 操作日志覆盖全部资金类操作（调额、结算、提现审核、改费率、信用额度/权重设置）
