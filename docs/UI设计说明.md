# 衣搭库网页版 UI 设计说明

## 一、设计目标

- **产品定位**：基于真实衣橱的智能穿搭助手，简约高效、个性化。
- **目标用户**：20–35 岁职场人、学生，追求简约穿搭与个性表达。
- **设计原则**：信息清晰、操作路径短、视觉克制、适配桌面与移动端。

---

## 二、信息架构与页面结构

### 2.1 主导航（一级页面）

| 模块       | 路由/入口     | 说明                         |
|------------|----------------|------------------------------|
| 首页       | `/` 或 首页    | 天气、每日推荐入口、快捷场合 |
| 衣橱       | `/wardrobe`    | 衣物列表、筛选、上传入口     |
| 推荐       | `/recommend`   | 生成推荐、穿搭卡片           |
| 我的收藏   | `/favorites`   | 已收藏的穿搭方案             |
| 穿搭记录   | `/diary`       | 穿搭日记、日历回顾           |
| 设置       | `/settings`    | 偏好、推送、账号             |

### 2.2 次级页面与弹层

- **上传流程**：选择照片 → 上传/识别进度 → 识别结果卡片（可编辑）→ 保存。
- **上传队列**：独立入口或衣橱内入口，展示待上传/上传中/失败任务。
- **用户偏好**：首次引导 3–4 步（风格、场合、体型、颜色等）；设置页可修改。
- **推荐详情**：单套穿搭的完整信息、换一件、收藏、分享。
- **衣物编辑**：单品详情/编辑表单（品类、颜色、风格、季节、标签、备注）。

## 三、视觉规范

### 3.1 色彩

- **主色**：`#2C2C2C`（深灰，标题与重要文字）。
- **背景**：`#FAF9F7`（暖白），次要区域 `#F5F3F0`。
- **强调色**：`#C4A574`（暖金/米棕），用于主按钮、选中态、关键信息。
- **功能色**：成功 `#4A7C59`，警告 `#C9A227`，错误 `#B85450`，链接 `#5B7C9D`。
- **中性**：边框与分割 `#E8E6E3`，辅助文字 `#8E8C89`。

### 3.2 字体

- **标题**：Noto Serif SC / 思源宋体，字重 600，营造「衣橱/杂志」感。
- **正文与 UI**：Noto Sans SC / 思源黑体，常规 400，中等 500。
- **层级**：H1 24px，H2 20px，H3 18px，正文 15px，辅助 13px；行高 1.4–1.6。

### 3.3 圆角与阴影

- **卡片**：圆角 12px，阴影 `0 2px 12px rgba(0,0,0,0.06)`。
- **按钮**：主按钮圆角 8px；筛选标签（Chip）圆角 20px。
- **图片**：衣物/穿搭缩略图圆角 8px。

### 3.4 间距

- **页面边距**：移动端 16px，桌面端 24px；最大内容宽度 1200px 居中。
- **组件间距**：卡片之间 16px，区块之间 24px。

## 四、核心页面线框与组件

### 4.1 首页

- **顶部**：Logo + 可选「设置」入口；可选网络状态/离线提示条。
- **天气卡片**：城市、温度、天气状况、简短穿衣提示（如「适合薄外套」）。
- **每日推荐入口**（推送关闭时显示）：卡片文案「今日推荐」「点击查看今日穿搭推荐」，点击即用默认场合+当日天气生成推荐。
- **快捷场合**：横向滚动 Chip：「通勤」「约会」「运动」「聚会」等，点击即带当日天气生成推荐。
- **底部导航**：首页、衣橱、推荐、收藏、我的（或整合进「我的」：设置、穿搭记录等）。

### 4.2 衣橱页

- **顶部**：标题「我的衣橱」+ 上传按钮（主操作）+ 上传队列入口（若有待处理任务）。
- **筛选栏**：横向滚动；项：全部、已淘汰(数量)、上衣、裤子、裙子、鞋子、配饰，以及风格/季节/颜色等（可折叠或二级筛选）。选中态用主色/填充区分。
- **视图切换**：网格 / 列表；网格 2–3 列可配置。
- **衣物卡片（网格）**：缩略图、品类图标、颜色标签；支持多选（批量删除/标记已淘汰/恢复）。
- **衣物卡片（列表）**：缩略图 + 品类、颜色、风格、季节、标签、备注摘要。
- **搜索**：按备注、标签搜索，置于筛选栏旁或顶部。

### 4.3 推荐页

- **场景选择**：场合 + 天气（或默认当日天气）；可与首页快捷场合一致。
- **结果区**：3–5 套穿搭卡片，每套含：
  - 单品缩略图（可点击「换一件」）、搭配亮点、适用场景；
  - 操作：收藏、分享、应用。
- **冷启动**：衣橱不足或缺少关键品类时，展示引导文案、基础搭配模板卡片、缺失品类提示与「去上传」入口。

### 4.4 上传流程

- **选择照片**：多选（最多 9 张），支持拖拽；显示已选数量。
- **进度**：整体进度条 0–50% 上传、50–100% 识别；文案「AI 正在识别中…」。
- **结果**：每张对应一张识别结果卡片（品类、颜色、风格、季节等），可编辑后保存。
- **失败/重试**：单条失败提示与「重新识别」；网络恢复后「正在恢复上传」弹窗与后台续传。

### 4.5 用户偏好（首次引导 / 设置）

- **步骤**：风格多选 → 常去场合多选 → 身高/体重（可选）→ 颜色偏好（可选）→ 穿搭原则多选。
- **每步**：标题 + 简短说明 + 多选/输入 + 「下一步」「跳过」。
- **设置页**：同一批偏好可修改；推送时间、工作日/周末；账号与隐私入口。

## 五、交互与状态

- **筛选**：多条件组合，实时更新列表；「已淘汰」与品类等可同时生效。
- **换一件**：点击单品 → 底部或侧边抽屉展示同品类列表 → 选择后展示「AI 正在重新评估…」→ 更新该套穿搭并标注「已重新优化」。
- **收藏**：心形图标，未收藏/已收藏区分；收藏列表独立页。
- **离线**：顶部横幅提示；上传、生成推荐、同步等按钮禁用并提示连接网络。
- **加载**：列表/推荐使用骨架屏或占位图；上传/识别用进度条与文案。

---

## 六、响应式与适配

- **断点**：以 768px 为界，以下为移动端，以上为平板/桌面。
- **移动端**：单列或两列网格；筛选栏横向滚动；主要操作固定底部或悬浮按钮。
- **桌面端**：内容最大宽度 1200px；衣橱可 3 列；推荐卡片可 2 列或横向滑动。

---

## 七、可访问性与规范

- 按钮与链接具备清晰焦点态；关键操作有足够点击区域（约 44px 高）。
- 重要信息不依赖单一颜色传达；对比度符合 WCAG 2.1 AA。
- 图片提供 alt 文案；表单有 label 与错误提示。
